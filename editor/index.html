1. Connect to GitHub

Use a fine-grained personal access token for gunpowderstudios/website, with Contents: Read and write. The token stays in this browser tab's memory and is never saved in the website or sent anywhere except GitHub.

Create a limited GitHub token (choose only the website repository, Contents read/write, and a short expiry). Anyone may open this editor page, but only someone with repository write access can publish.

2. Choose a page

3. Click text or an image in the preview

Double-click text on the page to edit directly, with the text box growing automatically. Click outside to finish. Single-click to edit in the left panel, or select an image to replace it. Navigation links are not editable.

Choose a page to preview it. Connect to GitHub to make edits.

For paragraphs containing bold or inline styling, replacing the text removes that paragraph's inline formatting.

Photos and artwork are converted to WebP, up to 2,000px wide, and named with the page name for SEO. Animated GIFs become a still image.
